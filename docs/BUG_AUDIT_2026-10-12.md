# Bug Audit — 2026-10-12

Static and test-driven audit of `lib/` (about 16.5k lines), including the uncommitted PDF XMP work present in the tree on this date.

**Baseline before the audit:** `flutter analyze` reported no issues, and `flutter test` passed 528 tests with 1 skipped, on the local Flutter 3.41.7. Every bug below is one the existing suite does not catch.

**Evidence column:**
- **test**: reproduced with a throwaway test. The test was deleted afterwards and is rewritten as part of the fix plan.
- **real file**: reproduced on a real-world file.
- **code**: found by reading the code; strong, but not executed.
- **verify**: suspected defect whose symptom still needs a reproducing test before it is fixed.

**Status (2026-10-12): all C, H, M findings and L1-L11 are fixed on `fix/bug-audit-2026-10-12`; the Task column shows the fixing commit(s). "Manual verification pending" means covered by tests only, not yet checked by hand. L12 is backlog and now tracked in `docs/IMPLEMENTATION_PLAN.md`.**

Fix plan: `docs/superpowers/plans/2026-10-12-bug-fixes.md`. Task numbers are shown in the **Task** column.

## Reviewed and found clean

- **Strippers:** BMP; WebP (VP8X flags, padding, RIFF size); WAV INFO selective; FLAC validator and FLAC full/selective strip; ID3 stripper core; PNG strip (CRC, chunk set, data after IEND); JPEG marker walk and entropy handling; PDF XMP packet parser and validator; the uncommitted Info+XMP range merging.
- **ZIP preflight:** traversal, duplicate names, symlinks, encryption, ZIP64, local/central mismatch and overlap checks. `rewriteZipMetadata` comment and time zeroing. Namespace-URI matching. Content-type and relationship cleanup on full strip.
- **Orchestration:** selective-ID allowlists agree across the policy, bloc and `MetadataFieldId.parse`. Isolate closures are sendable. Size caps are consistent. The claim/tmp clean-copy logic is sound. `content://` outputs are never touched locally.
- **Viewer:** EXIF loop safety, WebP/BMP/GIF walkers (correction from the final review: the viewer GIF walker had the same image-descriptor off-by-one as C1; fixed in the final fix wave), the SHA-256 100 MB cap, the MP3 tail boundary, field-ID parity in both directions, selective UI gating, ViewerCubit.
- **App:** bootstrap retry, the onboarding gate, the SAF validator, settings import hardening, export redaction, atomic reset, SettingsCubit queueing, theme fallbacks, Gradle signing.
