Privacy Policy

Last updated: August 10, 2026 Applies to: MetaStrip - Metadata Viewer & Remover (the "App")

Summary. MetaStrip is designed for privacy. All file processing happens on your device. We do not collect, store, or share your personal data.

1. Data We Collect

1.1 Personal Data

MetaStrip does not collect personal data such as your name, email, phone number, or any other identifier.

1.2 Files and Metadata

  • The App does not upload your files or metadata to any server.
  • Files are processed entirely in device memory to extract and remove metadata.
  • Results are saved as clean copies in the output folder you choose.
  • Original files are not changed or moved.

1.3 Local App Data

MetaStrip stores the following settings locally on your device through SharedPreferences:

  • Onboarding status (completed or not)
  • The output folder path you chose
  • Color theme preference
  • Other app settings (portable JSON format)

This data is never sent to a server.

2. Permissions Used

2.1 Android

  • System File Picker / SAF (Storage Access Framework): to pick files and the output folder explicitly. No broad storage permission such as READ_MEDIA_* or MANAGE_EXTERNAL_STORAGE is required.
  • The App does not request camera, contacts, location, or device identity access for metadata extraction.

2.2 iOS

  • File Picker / Files app integration: to pick files and choose the output location.
  • The App does not request broad access to device photos or the media library.

3. How Data Is Used

  • The files you pick are used only for:
    • Extracting metadata to show in the Viewer
    • Removing metadata to create a clean copy in the Remover
  • Extracted metadata is shown in app memory only and is not stored permanently.
  • Clean copies are saved to the location you choose; that folder is managed by your device's file system.

4. Data Sharing

MetaStrip does not share data with third parties because there is:

  • No backend server
  • No analytics SDK (such as Firebase Analytics or Google Analytics)
  • No ad SDK (such as AdMob or Unity Ads)
  • No social media integration that sends data
  • No third-party cloud service

5. Data Retention

  • Your original files are never touched by the App.
  • Clean copies are stored on your device under standard file system controls.
  • App settings (SharedPreferences) remain on the device until you:
    • Uninstall the App
    • Reset data through Settings → Reset All Data
    • Clear the app's data in system settings

6. Security

  • File processing happens entirely on your device.
  • No data is transmitted over the network.
  • Original files are protected by the operating system; the App only reads files you explicitly pick.
  • Clean copies are written to a new location; originals are not modified.
  • SHA-256 hashes are computed on-device for files up to 100 MB (optional).

7. Third-Party Services

MetaStrip does not include third-party SDKs that collect data. Main dependencies:

  • Flutter SDK (UI framework)
  • Dart standard library
  • Packages: archive, xml, exif, image, path, mime, crypto, file_picker, file_selector, saf, shared_preferences

All of these packages run code on your device and do not send data out.

8. Your Rights

You have full control over:

  • Which files are processed (through the system picker)
  • Where clean copies are saved (the folder you choose)
  • Which metadata is shown and removed
  • Deleting all app data through reset or uninstall

9. Changes to This Policy

This policy may be updated as the App evolves. Significant changes will be clearly documented. The latest version is always available on this page.

10. Contact

For questions about privacy or the App, email hello@bariskode.com.

Important Notes

  • The App is not designed for children under 13.
  • No location, identity, or user behavior data is collected.
  • If you install the App through Google Play, Google applies its own privacy policy, which is outside MetaStrip's control.
