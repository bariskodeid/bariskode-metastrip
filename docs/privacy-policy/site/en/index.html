Features

See it first, then strip it

Photos, documents, and recordings often carry a location, device name, author, or edit history. MetaStrip shows all of it before you share the file.

Full viewer

Filesystem metadata, EXIF, audio tags, document properties, and archive entries, neatly grouped.

Clean copy, original intact

The result is always a new _clean file in the folder you choose. Name clashes get a number and are never overwritten.

Selective removal

Pick specific fields: PNG text chunks, PDF DocInfo, FLAC Vorbis comments, WAV LIST INFO, and Office and ODF properties.

21 removal formats

Images, PDF, Office, ODF, audio, ZIP, APK, and EPUB. The Viewer reads more than 40 extensions.

Controlled processing

Files are processed one by one with progress, a per-file log, and a cancel button. Each result is re-validated after writing.

Copy values

Copy metadata values to the clipboard to note them down or compare them.

7 themes + custom

Dark Industrial, Steel Blue, Acid Green, and more, plus a custom theme builder with 16 color tokens.

Portable settings

Export and import settings as JSON. A two-step reset leaves the clean copies you already made in place.

How it works

Three steps, no uploads

No account, no internet connection, and no broad storage permission.

  1. Pick a file

    Open files through the system file picker. MetaStrip only reads the files you pick yourself.

  2. Inspect the metadata

    See what the file carries. Strip all supported metadata, or pick just the fields you want gone.

  3. Save a clean copy

    MetaStrip writes a new file to your output folder and re-validates it. The original stays exactly as it was.

You choose the output folder once during onboarding and can change it any time in Settings.

Limits in this version

  • PDF removal is best-effort: it blanks the trailer-referenced Info dictionary and XMP; PDFs with Info in a compressed object stream are rejected.
  • BMP is limited to the canonical 24/32-bit Windows BITMAPINFOHEADER subset.
  • ZIP, APK, and EPUB are cleaned at the container level only, not recursively. A cleaned APK is no longer signed.
  • Selective removal covers supported standard metadata IDs only; custom and legacy Office properties are not supported yet.
  • Video and HEIC/HEIF can be viewed but not cleaned yet.

FAQ

Frequently asked questions

Are my files uploaded to a server?

No. All metadata extraction and removal runs on your phone. MetaStrip has no backend server, ships no analytics or ad SDKs, and the release build does not request the internet permission.

Does MetaStrip change my original file?

No. MetaStrip always writes a new file named <name>_clean to the output folder you chose. If that name is taken, it adds a number. The original is never overwritten, moved, or deleted.

Which formats can it clean?

JPG/JPEG, PNG, GIF, WebP, BMP, PDF, DOCX, XLSX, PPTX, ODT, ODS, ODP, MP3, FLAC, OGG, Opus, WAV, AIFF, ZIP, APK, and EPUB. The Viewer reads more formats, including video, HEIC, TIFF, and RTF.

Is all metadata guaranteed to be removed?

MetaStrip removes the metadata it supports for each format. PDF removal is best-effort: it blanks the trailer-referenced Info dictionary and XMP, and rejects PDFs that keep Info in a compressed object stream. ZIP, APK, and EPUB are cleaned at the container level only, not the files inside. Open the result in the Viewer to double-check.

Why can't I install a cleaned APK?

Cleaning container metadata changes the package contents, so the APK signature no longer verifies. Use a cleaned APK for archiving or sharing as a file, not for installing.

Is there a file size limit?

The Remover accepts files up to 50 MiB. For ZIP, Office, ODF, APK, and EPUB, the decompressed contents are capped at 32 MB and 2,000 entries so processing stays safe in phone memory.

Which phones are supported?

Android phones running Android 7.0 or later.
