Fitur

Lihat dulu, lalu bersihkan

Foto, dokumen, dan rekaman sering membawa lokasi, nama perangkat, nama penulis, atau riwayat edit. MetaStrip menunjukkan semuanya sebelum Anda membagikan file.

Viewer lengkap

Metadata filesystem, EXIF, tag audio, properti dokumen, dan entri arsip, dikelompokkan dengan rapi.

Clean copy, original utuh

Hasil selalu berupa file baru _clean di folder pilihan Anda. Nama yang bentrok diberi nomor, tidak pernah ditimpa.

Hapus selektif

Pilih field tertentu: text chunk PNG, DocInfo PDF, Vorbis comment FLAC, WAV LIST INFO, serta properti Office dan ODF.

Cara kerja

Tiga langkah, tanpa upload

Tanpa akun, tanpa koneksi internet, dan tanpa izin storage yang luas.

  1. Pilih file

    Buka file lewat file picker sistem. MetaStrip hanya membaca file yang Anda pilih sendiri.

  2. Periksa metadata

    Lihat apa saja yang tersimpan di file. Bersihkan semua metadata yang didukung, atau pilih field tertentu saja.

  3. Simpan clean copy

    MetaStrip menulis file baru ke folder output Anda dan memvalidasinya ulang. File asli tetap seperti semula.

Folder output dipilih sekali saat onboarding dan bisa diganti kapan saja di Settings.

Batasan versi ini

  • PDF bersifat best-effort: Info dictionary dan XMP yang dirujuk trailer dikosongkan; PDF dengan Info di compressed object stream ditolak.
  • BMP terbatas pada subset kanonik 24/32-bit Windows BITMAPINFOHEADER.
  • ZIP, APK, dan EPUB dibersihkan di level container saja, tidak rekursif. APK hasil cleanup tidak lagi ter-sign.
  • Hapus selektif hanya untuk ID metadata standar yang didukung; properti custom dan legacy Office belum didukung.
  • Video dan HEIC/HEIF baru bisa dilihat, belum bisa dibersihkan.

FAQ

Pertanyaan yang sering diajukan

Apakah file saya diupload ke server?

Tidak. Semua ekstraksi dan penghapusan metadata berjalan di HP Anda. MetaStrip tidak punya server backend, tidak memuat SDK analytics atau iklan, dan versi rilisnya tidak meminta izin internet.

Apakah file asli saya diubah?

Tidak. MetaStrip selalu menulis file baru bernama <nama>_clean di folder output yang Anda pilih. Jika nama itu sudah ada, MetaStrip menambahkan nomor. File asli tidak ditimpa, dipindah, atau dihapus.

Format apa saja yang bisa dibersihkan?

JPG/JPEG, PNG, GIF, WebP, BMP, PDF, DOCX, XLSX, PPTX, ODT, ODS, ODP, MP3, FLAC, OGG, Opus, WAV, AIFF, ZIP, APK, dan EPUB. Viewer bisa membaca lebih banyak format, termasuk video, HEIC, TIFF, dan RTF.

Apakah semua metadata pasti terhapus?

MetaStrip menghapus metadata yang didukung untuk tiap format. Untuk PDF prosesnya best-effort: Info dictionary dan XMP yang dirujuk trailer dikosongkan, dan PDF yang menyimpan Info di compressed object stream ditolak. ZIP, APK, dan EPUB hanya dibersihkan di level container, tidak sampai file di dalamnya. Buka hasilnya di Viewer untuk memeriksa ulang.

Kenapa APK hasil cleanup tidak bisa di-install?

Membersihkan metadata container mengubah isi paket, sehingga tanda tangan APK tidak berlaku lagi. Gunakan APK hasil cleanup untuk diarsipkan atau dibagikan sebagai file, bukan untuk di-install.

Apakah ada batas ukuran file?

Remover menerima file hingga 50 MiB. Untuk ZIP, Office, ODF, APK, dan EPUB, total isi setelah dekompresi dibatasi 32 MB dan maksimal 2.000 entri, supaya proses tetap aman di memori HP.

HP apa saja yang didukung?

HP Android 7.0 ke atas.
