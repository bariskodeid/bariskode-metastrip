# Audit antislop 001: landing page MetaStrip

- Tanggal: 2026-11-04
- Mode: AFTER (audit dulu, perbaikan hanya untuk nomor yang disetujui)
- Target: https://metastrip.bariskode.com/ dan /en/ (versi live), sumber di `docs/privacy-policy/site/`
- Batasan dari pemilik: badge resmi "Dapatkan di Google Play" / "Get it on Google Play" dipertahankan apa adanya.
- Design Read: landing page aplikasi utilitas privasi untuk pengguna Android yang peduli jejak file, bahasa visual "Industrial Minimalism" dari `docs/DESIGN.md` (rust + steel, monospace, sudut tegas), dial ENERGY 2 / RHYTHM 2 / MOTION 1.
- Cara cek: screenshot Playwright 1366x850 dan 390x844, pengukuran kontras dengan antislop contrast checker, baca HTML/CSS live.

## Prasyarat: repo tertinggal dari situs live

Isi `docs/privacy-policy/site/` di repo **lebih lama** dari yang ter-deploy. Versi live sudah memakai badge resmi (`/img/google-play-badge-id.svg`, `-en.svg`, class `.play-badge`), schema `sameAs`/`downloadUrl`, dan `site.css?v=20261028`. Repo masih memakai tombol buatan sendiri `.btn-store` dengan ikon HP, dan file SVG badge tidak ada di repo.

Kalau perbaikan dikerjakan dari repo lalu di-deploy, badge resmi akan hilang. Jadi langkah pertama sebelum nomor mana pun: sinkronkan versi live ke repo (HTML, CSS, dua SVG badge), tanpa script yang disuntik Cloudflare (`/cdn-cgi/...`, email obfuscation).

## Diperiksa dan lolos (tidak perlu diubah)

- Badge Google Play: artwork resmi, tinggi 56px, alt sesuai bahasa, ada catatan merek dagang di footer. Dipertahankan.
- FAQ spesifik produk (upload, file asli, APK tidak bisa di-install, batas 50 MiB). Lolos R-28.
- Tidak ada statistik, testimoni, atau klaim keamanan karangan. Klaim offline dan tanpa izin internet sesuai kode aplikasi.
- Tidak ada overflow horizontal di 390px (scrollWidth = clientWidth). Gutter 16px, target sentuh 44px+.
- Nav menunjuk ke section yang ada. Menu mobile, galeri, dan FAQ (`<details>`) berfungsi tanpa JS mati.
- Gambar punya `width`/`height`, gambar hero `fetchpriority="high"` + preload, galeri `loading="lazy"`, `site.js` memakai `defer`.
- Grid tipis di hero punya alasan tertulis ("engineering grid, like a spec sheet") yang cocok dengan identitas industrial. Lolos R-07. Opsional: DESIGN.md sebenarnya menyebut noise texture, bukan grid.
- Blur hanya di header (1 elemen). Lolos R-10.

## Rekomendasi pilihan

- Wajib minimal: prasyarat sinkron + 1 sampai 6 (semua HIGH, perbaikan kecil di CSS/meta).
- Dampak UX terbesar: 7, 11, 12, 14. Nomor 11 butuh aset baru, yaitu screenshot asli layar detail metadata dan hasil clean copy (bisa diambil dengan helper adb di `scripts/`). Tanpa screenshot itu, saya hanya bisa menata ulang hero dengan gambar yang sudah ada.
